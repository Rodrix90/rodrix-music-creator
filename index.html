Aviso de Coincidencia en Catálogo Comercial

Filtro automatizado del proveedor Udio API

La API identificó que la melodía coincide con una grabación comercial registrada en su catálogo automatizado y reembolsó los créditos. Al tratarse de una grabación propia de un himno clásico o composición en dominio público, puedes solicitar una revisión manual al proveedor.

Pasos para solicitar revisión al proveedor:
  1. Descarga el Informe de Diagnóstico adjunto (incluye el ID de tarea, fecha y mensaje exacto sin datos sensibles).
  2. Envía un correo a soporte de la API: support@udioapi.pro.
  3. Indica que se trata de una interpretación propia de una obra tradicional de dominio público (ej. himno del siglo XIX).
